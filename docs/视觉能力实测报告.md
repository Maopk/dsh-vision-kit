# 「没有 DOM 时怎么办」——本机视觉能力实测结论表

测试图：本机原生截屏 `self-look-*.png`（2560×1600，dpr 1.5，由本仓库插件拍摄）
真值来源：DOM `getBoundingClientRect()` × 1.5

> 仓库里**不放界面截图**（会暴露会话内容）。所有结论都带数值，复现命令在下面——在你自己机器上跑一遍就能得到同样的数字。

## 结论表（按可信度排序）

| # | 方法 | 工具 | 目标 | 实测结果 | 可信度 |
|---|---|---|---|---|---|

## 一句话总结

- **几何量测**：像素方法（模板匹配 / 长边检测）能到 **1 px 级**，不需要模型；但必须**用真值打分**，否则写错了也看不出来。
- **文字**：tesseract 在本机深色 UI 上可用（`--psm 6`），中文+金额都能读。
- **语义定位**：8 GB 显存能跑的本地 VLM（2b/3b）**只能告诉你"大概在右下角"**，不能给框。要精确框就得靠模板/DOM，或换更大的 grounding 专用模型。

## 复现命令

```powershell
$py    = "python"                                              # 需要 numpy + Pillow
$shot  = (Get-Content "$env:USERPROFILE\.dsh-look-last.txt")   # 最近一张原生截屏
$asset = "$env:USERPROFILE\.dsh\profiles\desktop\node_modules\dsh-whale-widget\assets\DSniang1.png"
$truth = "2337,1305,2561,1529"                                 # 换成你自己元素的 DOM 真值 × dpr

# 模板匹配（本例 IoU 0.991）
& $py tools\template_match.py $shot $asset --scales 0.34,0.3656,0.40 --expect $truth

# 边框线检测（本例差 1 px）
& $py tools\cv_ui_geometry.py $shot --noise 3 --min-run 250 --expect $truth --annotate .\cv.png

# 模型 grounding 打分（本例给出 6 种坐标解释里最好的那个）
& $py tools\ground_test.py --image $shot --model granite3.2-vision:2b `
  --prompt 'What is the bounding box of the whale?' --expect $truth
```

## 踩坑记录（重要）

1. **第一次"正经管线"其实报了个假结果**：`longest_run()` 沿 axis 0 累计、按列返回，我却传了 `d.T`，于是量的是"水平方向的连续边"，得出"整图 0 条边框"。修复后立刻在 x=419 找到 1450 px 的连续边——**和 DOM 真值只差 1 px**。教训：没有真值打分，这种错误会一直藏着。
2. **模型坐标系不统一**：granite 文档写 0–1000 归一化，实际输出 0–1 小数；qwen 输出的是它收到的那张图的像素。`ground_test.py` 现在把 6 种解释全算一遍再取最优，避免"解析错=IoU 0"的假结论。
3. **深色 UI 的对比度极低**：面板 27/255 vs 背景 21/255，单步差 5.67，任何"高对比边缘"假设都会失效，必须把阈值降到 3 并靠连续长度过滤文字。
